## High-Confidence Findings (3/3 Tracks Agree)

- [ ] **High — the live-provider Lever-2 acceptance claim is contradicted by the gate command.**  
  The claimed real Google/LLM sample calls `runSampleWaterfall` with `lever2FixedGeometry`, injecting the reconstruction outcome instead of obtaining ordered LLM anchors, geocoding them, and routing them. The couch evidence later contains only `test:*` records.  
  **Evidence:** `.gate-evidence/2026-07-19T22:59:46Z/scripts/step1.sh:4-11`; `convex/waterfallOrchestrator.ts:574-588`; `GATE-RESULTS.md:6-9`.  
  **Remediation:** Keep this deterministic seam only as an integration test. Re-run the closeout gate with the seam prohibited, live-provider request/result provenance retained (secrets redacted), and actual recovered catalog routes.

- [ ] **High — `classifyCatalog` does not classify the catalog.**  
  With no caller-supplied IDs, it sets `ids = []` and returns zero classifications. This fails S4-T4's required whole-catalog behavior and leaves no production path that enumerates all eligible routes.  
  **Evidence:** `convex/actions/rideWorthinessClassifier.ts:226-238,255-265`; the integration test only supplies a fixture subset at `convex/__tests__/S4T4-classify-catalog.integration.test.ts:98`.  
  **Remediation:** Add bounded/paginated eligible-route enumeration with checkpointing, coverage counters, and a completion condition that fails while eligible routes remain unclassified.

- [ ] **High — the founder couch gate is automated fixture approval, not founder review.**  
  Step 3 seeds 30 `test:*` fixtures; step 4 generates a `true` verdict for every sampled route and records `pass`. PNG byte count is checked, not geographic correctness or a person's visual disposition.  
  **Evidence:** `.gate-evidence/2026-07-19T22:59:46Z/scripts/step3.sh:6-35`; `.gate-evidence/2026-07-19T22:59:46Z/scripts/step4.sh:5-18`; `.gate-evidence/2026-07-19T22:59:46Z/step3.log`; `.gate-evidence/2026-07-19T22:59:46Z/step4.log`.  
  **Remediation:** Create an authenticated founder workflow over a real immutable sample/export manifest; record reviewer identity, image/geometry hashes, route decisions and notes. Keep fixture seeding out of production closeout evidence.

## Medium-Confidence Findings (2/3 Tracks Agree)

- [ ] **Critical — a couch-pass record can be forged or replaced and then unlock `--all`.**  
  `recordCouchVerdict` only rejects an empty list and a pass containing `wrong`; it does not load/validate the sample, require exact one-to-one membership, reject duplicates/unrelated IDs, or bind the pass to a catalog snapshot. `couchGateStatus` accepts the newest stored pass.  
  **Evidence:** `convex/couchVerdict.ts:51-101,128-145`; gate step 8 clears/recreates the pass programmatically at `.gate-evidence/2026-07-19T22:59:46Z/scripts/step8.sh:5-30`.  
  **Remediation:** Require a real immutable sample, exact unique verdict coverage of its route IDs, approved founder/operator authorization, reviewer identity, and invalidation when the sample's geometry/catalog version changes.

## Low-Confidence Findings (Single Track; Verify During Remediation)

- [ ] **Critical — REVIEW approval bypasses canonical verification.** `approveDisposition` rewrites a REVIEW candidate to `verification.verdict: 'pass'` and `riderReady: true` without calling the geometry gate. **Evidence:** `convex/reviewQueue.ts:235-292`. **Remediation:** re-run the canonical gate; model any explicit override separately, with privileged authorization, immutable rationale, and no automatic rider-ready state for a failing geometry.

- [ ] **High — operational mutations rely on authentication rather than founder/operator authorization.** REVIEW approve/retry/retire and couch verdict record/clear call `requireIdentity` without a role/ownership check. **Evidence:** `convex/guards.ts:15-28`; `convex/reviewQueue.ts:236-239,317-320`; `convex/couchVerdict.ts:51-58,151-156`. **Remediation:** make operational commands internal or enforce a server-side founder/admin role using canonical identity data.

- [ ] **High — new-geometry region validity is not enforced by the canonical verdict function.** `determineGateVerdict` uses caller-provided `anchorCount`, while distance checks live only in `reevaluateExistingGeometry`. **Evidence:** `convex/curatedGeometryGate.ts:99-128,146-183`. **Remediation:** pass verified anchors/centroid (or an independently computed in-region count) to the canonical gate for every lever.

- [ ] **Medium — couch sampling prefers test fixtures when present.** **Evidence:** `convex/couchSampleAssembler.ts:565-580`. **Remediation:** exclude test namespaces by default and expose fixture sampling only in test-only endpoints.

- [ ] **Medium — cost stopping can leave an attempted route without a terminal disposition.** **Evidence:** `convex/waterfallOrchestrator.ts:518-560`. **Remediation:** persist an explicit resumable `deferred_cost_limit` terminal state or perform the affordability check before any lever work.

- [ ] **Medium — classifier type boundaries use `any`, contrary to the project Convex guidance.** **Evidence:** `convex/actions/rideWorthinessClassifier.ts:129-133,166`; `convex/_generated/ai/guidelines.md`. **Remediation:** use typed contexts/function references and `Id<"curated_routes">` rather than casts.
